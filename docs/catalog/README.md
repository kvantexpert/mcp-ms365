# MCP-MS365 Catalogs

Документационные каталоги MCP-MS365. Они не заменяют runtime configuration.

## Structure

- application-registry/ — идентичность приложений и Client ID.
- permission-catalog/ — полный каталог возможных Microsoft Graph permissions.
- preset-registry/ — безопасные рабочие профили MCP и их effective scopes.
